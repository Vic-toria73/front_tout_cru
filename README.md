# ToutCru
Projet d'un calcultateur de ration BARF.
Ce calculateur est pensé pour faciliter la vie des propriétaires de chien pour : 
      - les préparations des rations
      - les commandes de viandes en amont
      - le suivi du poids du chien.

# BARF = Biologically Appropriate Raw Food, soit Nourriture Crue Appropriée Biologiquement
